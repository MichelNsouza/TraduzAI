# Primeiro teste do agente

Antes de trabalhar com uma ISO, valide o ambiente.

## Teste de contexto

O agente deve ler:

- README.md
- AGENTS.md
- context/mission.md

E explicar o objetivo do projeto.

## Teste de execução

Criar:

scripts/test.py

O script deve imprimir:

TraduzAI funcionando

Depois executar o script.

## Teste de relatório

Criar:

reports/environment.md

Contendo:

- sistema operacional;
- versão do Python;
- ferramentas instaladas.
