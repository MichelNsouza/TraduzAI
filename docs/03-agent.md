# Configuração do Agente de IA

O TraduzAI utiliza agentes capazes de:

- ler arquivos;
- criar arquivos;
- editar código;
- executar comandos no terminal.

## Agentes compatíveis

- Roo Code
- GitHub Copilot
- Claude Code
- Gemini CLI

## Configuração recomendada

VS Code + Roo Code + Gemini.

## Permissões necessárias

O agente deve permitir:

- executar comandos;
- criar arquivos;
- editar arquivos;
- acessar o projeto.
