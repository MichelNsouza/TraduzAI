# Configuração da API Gemini

O TraduzAI utiliza modelos de IA para auxiliar no processo de análise e tradução.

## Criar API Key

1. Acesse o Google AI Studio.
2. Faça login com uma conta Google.
3. Crie uma nova API Key.
4. Copie a chave gerada.

## Segurança

Nunca:

- publique sua API Key;
- coloque a chave dentro do repositório;
- compartilhe a chave.

## Configuração

A API Key deve ser configurada no agente de IA escolhido.
