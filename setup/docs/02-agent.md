# Configuração do Agente de IA

O TraduzAI utiliza agentes capazes de:

- ler arquivos;
- criar arquivos;
- editar código;
- executar comandos no terminal.

## Agentes compatíveis

- Roo Code
- GitHub Copilot
- Claude Code
- Gemini CLI

## Configuração recomendada

VS Code + Roo Code + Gemini.

## Permissões necessárias

O agente deve permitir:

- executar comandos;
- criar arquivos;
- editar arquivos;
- acessar o projeto.

## Orientação

O ponto de entrada é o `AGENTS.md`. Siga a trilha de leitura e consulte `01-install.md`, `03-pipeline.md` e `04-convencoes.md` para saber como atuar e o que promover ao repositório.
