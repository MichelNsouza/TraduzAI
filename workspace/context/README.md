# context/ — conhecimento acumulado

Aqui vive o material de apoio versionado: o que serve para **outros jogos**.

Contém:

- Descobertas de engenharia reversa (formatos, encodings, engines).
- Documentação de formatos identificados.
- Glossários de tradução (termos EN→PT).
- Lições aprendidas de outros jogos.
- Templates de relatório em `templates/`.

Regras:

- 1 doc por descoberta/formato/lição.
- Nada de binários ou arquivos grandes aqui.
- Ao iniciar um jogo novo, consulte este acervo primeiro.
